# منصة إدارة البطولات الرياضية

نظام متكامل لإدارة البطولات الرياضية (كرة القدم، البادل) مبني بهيكل قابل للتوسع (Scalable) وموجه نحو الأجهزة المحمولة (Mobile First).

## مميزات النظام (النسخة الأولى MVP)
1. **الزوار:** تصفح البطولات، المباريات، الإحصائيات، بدون تسجيل دخول.
2. **المستخدمون:** تسجيل الدخول، إنشاء فرق، طلب الانضمام لبطولة.
3. **الإدارة:** لوحة تحكم كاملة، اعتماد التسجيلات، تحديث حالة الدفع يدوياً، وسجل نشاطات لمراقبة التغييرات.

## هيكل الملفات (8 ملفات فقط كحد أقصى)
1. `index.html` : الواجهة العامة وتصفح البيانات.
2. `app.html` : بوابة المستخدم المسجل لإدارة الفرق.
3. `admin.html` : لوحة تحكم الإدارة.
4. `style.css` : التنسيقات المشتركة والمتجاوبة.
5. `firebase.js` : إعدادات قاعدة البيانات والمصادقة.
6. `app.js` : منطق الواجهة العامة والمستخدمين.
7. `admin.js` : منطق الإدارة وصلاحياتها.
8. `README.md` : هذا الملف.

## كيفية التشغيل
1. قم بإنشاء مشروع جديد في [Firebase Console](https://console.firebase.google.com/).
2. فعّل خدمات **Firestore Database** و **Authentication (Email/Password)**.
3. انسخ مفاتيح الـ Config وضعها في ملف `firebase.js`.
4. افتح `index.html` في المتصفح وابدأ العمل!

*ملاحظة:* النظام مصمم لدعم دمج بوابات الدفع (Payment Gateways) والذكاء الاصطناعي (AI) مستقبلاً دون إعادة هيكلة قاعدة البيانات.
